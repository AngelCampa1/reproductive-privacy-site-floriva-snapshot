# Naming Candidates — Period Tracker Privacy

## Round 2 — Invented Names

| Name | Invented Etymology / Angle |
|------|---------------------------|
| Kylva | Coined from Norse "kyla" (cool, contained) clipped with a soft feminine ending — evokes calm control without any clinical or fear-based framing. |
| Rhovyn | Portmanteau of "rhythm" (biological cycles) + "haven" with a Scandinavian orthography twist — sounds like a real brand, implies sanctuary without saying "safe." |
| Lunaveil | "Luna" (moon, the universal cycle symbol) fused with "veil" clipped to a single visual unit — the moon meaning is felt rather than stated. |
| Telara | Completely coined; phonetically echoes "tela" (Latin: woven fabric, as in a network) + the -ara suffix common in trustworthy consumer brands (Lara, Tamara). |
| Privla | Clipped portmanteau of "priv-" (private) + Slavic diminutive "-la" — sounds like a name, not a descriptor; the privacy root is buried just enough to feel accidental. |
| Orvyn | Pure coinage built on "orb" (wholeness, cycle) + "-vyn" as an invented suffix; one syllable short of three, feels tech-adjacent like Figma or Vercel. |
| Cendri | From "cendre" (French: ash, something that leaves no trace) clipped to two syllables — implies data that doesn't persist, without any heavy-handed "delete" language. |
| Nixara | "Nix" (Latin/Germanic: nothing, zero) + "-ara" suffix — zero-trace data policy baked into the phoneme without being a slogan. |
| Floriva | Portmanteau of "flow" + "priva-" (private) collapsed into three syllables — competes directly with Flo on feel while signaling its opposite on data policy. |
| Veylo | Completely coined; vaguely echoes "veil" and "relay" — two syllables, ends in a vowel like Figma/Canva, generic enough to grow beyond period tracking, distinctive enough to trademark. |

Chosen: floriva.app
