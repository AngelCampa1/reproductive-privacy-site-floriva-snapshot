A period does not wait for a good day.

This kit covers the trips, events, work days, and workouts where a period can feel harder to plan around.

Use only the sections that fit your day.

It is not medical advice.

It does not tell you which period product to use.

For a small backup pouch, use the [period emergency kit checklist](/free/period-leak-and-product-kit).

For restocks, use the [period product refill plan](/free/period-leak-and-product-kit).

## Quick plan for any day away from home

Start here no matter where you are headed.

| Question | Your note |
|---|---|
| Where am I going? | |
| Expected period start date | |
| Expected heavy day | |
| Bathroom access | easy / hard / not sure |
| Products packed | |
| Backup clothes packed | |
| Who needs to know | |
| Main worry | |

Short notes help most.

"Day two may be heavy" is useful.

"Bathroom line before the show" is useful too.

## Beach and water park days

Beach and water park bathrooms can be far from your spot.

Find bathrooms before you set up.

| Place | Distance | Note |
|---|---|---|
| Closest restroom | | |
| Backup restroom | | |
| Shower or rinse area | | |
| Locker or car | | |
| Store or cafe | | |

This kit does not give swimming product instructions.

CDC Healthy Swimming has public guidance for staying healthy in and around pools, lakes, and oceans.

Check beach, pool, or park rules before you go.

Pack dry underwear, dry shorts or pants, a cover-up, and a small bag for wet clothes.

Keep the dry-clothes bag private if you want.

## Camp and school events

Camp cabins, school dances, and field trips often mean shared space and less privacy.

| Setting | Bathroom or bag plan | Trusted adult | Privacy note |
|---|---|---|---|
| Camp cabin | | counselor / nurse | plain labels on pouch |
| School dance | | teacher / nurse | outfit backup packed |
| Field trip | | chaperone / teacher | bag stays with me? yes / no |

Pack the products you already use, spare underwear, a plain pouch, small disposal bags, and a note about who can help.

Simple words work:

```text
I need the bathroom.

I need supplies from my bag.

Can I talk to the nurse?
```

Camps, schools, and trip leaders set their own rules. This kit does not promise what they allow.

## Conferences, festivals, and weddings

Long sessions, long lines, and long event days all need a bathroom and product plan.

| Event part | Bathroom nearby? | Product change plan | Backup |
|---|---|---|---|
| Morning session or ceremony | yes / no / not sure | | |
| Booth, dance floor, or crowd | yes / no / not sure | | |
| Meal or reception | yes / no / not sure | | |
| Travel home | yes / no / not sure | | |

Check bag rules and venue rules before you pack. Rules can change, and this kit does not know a specific venue's policy.

Save one low-detail line for help:

| Need | Script |
|---|---|
| A break | "I need a quick break. I will be right back." |
| Bathroom | "I need five minutes." |
| Help from a friend | "Can you bring my bag?" |

For weddings, pick one helper who can hold a backup kit and block a photo angle if needed. You do not have to explain the whole reason.

## Work meetings and long shifts

Periods do not wait for a good meeting time.

Pick one exit line before a long meeting or shift starts.

| Situation | Low-detail line |
|---|---|
| You can step away | "I need a quick health break. I will be right back." |
| You need coverage | "Can you cover me for five minutes?" |
| You cannot return | "I need to step out. Please send me the next steps." |

Before a long shift or meeting, check the closest bathroom, pack a backup product, and keep a plain calendar label such as "break" or "private note."

MedlinePlus lists cramps, lower back pain, bloating, headaches, fatigue, and mood changes among symptoms that can happen with menstruation. Mayo Clinic says to see a health care provider if cramps disrupt life every month, get worse, or start as severe cramps after age 25.

## Flights and road trips

Keep at least one day of supplies in the bag that stays with you.

| Travel part | Product plan | Backup count |
|---|---|---|
| Security and gate wait, or first hour of driving | | |
| Flight or long stretch of road | | |
| Layover or rest stop | | |
| Arrival | | |

TSA has a page for liquid medications and medically necessary liquids. Check it before you pack liquid medicine, and tell the officer at the start of screening if needed. This kit does not decide what TSA will allow.

CDC Travelers' Health has destination pages you can check before a trip.

For a stop or seat request, a short line is enough:

```text
I need the next bathroom stop.

I need the aisle seat.
```

## Dates, vacations, and everyday outings

Pack what you already use. Do not test a new product just for a date or a trip.

| Place | Bathroom access | Product change plan |
|---|---|---|
| Dinner, movie, or show | easy / hard / not sure | |
| Walk, hike, or tour | easy / hard / not sure | |
| Hotel or rental | easy / hard / not sure | |
| Ride home | easy / hard / not sure | |

Keep shared calendars plain. Try "dinner plan" instead of naming your period.

Plain lines can work with a date or friend:

- "I may need a bathroom stop."
- "I need to change plans tonight."
- "I am not feeling great, but I still want to go."

## Uniforms, running, sports, swimming, and the gym

Uniforms and workout clothes can make backup harder because you may not have many clothing choices.

| Setting | Backup layer | Kit spot | Words to use |
|---|---|---|---|
| Uniform or team kit | spare underwear, shorts, leggings | locker / bag / car | "I need clothing help." |
| Running or workout | product comfort check | reach bag | "Route had no bathroom." |
| Sports practice | compression shorts, towel | sports bag / locker | "I need my bag." |
| Swimming | dry clothes, wet bag | pool bag / locker | "I need dry clothes." |
| Gym | spare clothes, small trash bag | gym bag / locker | "I need my locker kit." |

CDC says physical activity is anything that gets the body moving, and some activity is better than none. This kit does not set training rules, pace, or intensity. It does not tell a team, school, or gym what rules to use.

ACOG says painful periods can happen before or during a period. Track a plain note if pain changes practice, a run, or a workout:

| Date | Setting | Pain note | What changed |
|---|---|---|---|
| | practice / run / swim / gym | | |

Ask a trusted adult or clinician if pain feels severe, new, or worrying.

## Hotel cleanup

For a fresh blood stain on hotel sheets, towels, or clothes, start with cold water on washable fabric if the care tag allows it.

The American Cleaning Institute says fresh blood stains should be soaked in cold water, hot water can set blood stains, and dried stains can be pretreated or soaked with an enzyme product.

| Step | Do this |
|---|---|
| 1 | Keep the stained item away from heat |
| 2 | Check the fabric tag if you can |
| 3 | Use cold water on washable fabric |
| 4 | Ask for fresh sheets or a laundry bag if needed |

A low-detail hotel script:

```text
Could I please get fresh sheets?
I also need a bag for laundry.
```

This does not promise a hotel will handle a stain a certain way, or that a stain will come out.

## Photos, location, and privacy

Photos and shared apps away from home can show more than you meant to share.

Check before you post or sync:

- Product pouch in a bag photo.
- Period app screens on a phone.
- Stain or leak photos.
- Bathroom, hotel, clinic, or store locations.
- Screenshots or group chats with health details.
- Location tags or live location sharing.

Turn off location sharing if you do not need it.

Use the [travel period data privacy checklist](/resources/privacy-in-practice/who-can-legally-get-your-period-data) before a trip, event, or work travel day.
