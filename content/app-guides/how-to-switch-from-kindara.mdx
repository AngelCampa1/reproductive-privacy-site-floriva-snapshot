## Before you switch

Kindara was a fertility awareness method (FAM) tracker popular with users who charted basal body temperature and cervical mucus. Prima-Temp acquired the app, and development has largely stopped. The app may still be installed on your phone, but it is no longer receiving updates, and its server infrastructure is in an uncertain state.

Unmaintained apps are a specific kind of privacy risk. Security patches stop. Server certificates can lapse. The company's data retention obligations become murky when the product is effectively abandoned. If Kindara's servers are still holding your fertility data, there is no active team maintaining the security of that data.

The priority here is data recovery, not a clean export-and-delete workflow.

## Export your data from Kindara

If Kindara still opens on your device, try the export path first. Check the app's settings menu for any data export or backup option. Older versions of Kindara supported CSV export of BBT charts and cycle data.

If the export function works, download the file immediately. Save it to a location you control, not a cloud sync folder if you are concerned about server copies of fertility data.

If the export function fails or the app will not connect to its servers, fall back to manual recovery. Open the app's calendar or chart view and photograph or write down:

- Your last 6-12 cycle start dates
- Any BBT data you want to preserve
- Cervical mucus observations if you were charting them
- Cycle length patterns

This is tedious but may be your only option for a discontinued app.

## Set up Floriva

Download Floriva and start the setup process. No account required, no email, no server registration. Your data stays on your device from the first entry.

Enter your recovered cycle start dates during onboarding. If you were using Kindara for fertility awareness charting, Floriva supports [BBT tracking](/app-guides/floriva-basal-body-temperature-tracking) and the [fertility awareness method](/app-guides/floriva-fertility-awareness-method-setup). Set up these features during initial configuration so you can continue charting without interruption.

## Rebuild your cycle history

Kindara users often have months or years of detailed charting data. Our [guide to rebuilding period history after switching apps](/compare/alternatives/rebuild-period-history-after-switching-apps) covers how to prioritize which data to transfer.

For FAM users specifically: cycle start dates and cycle length are the minimum for prediction accuracy. BBT patterns are valuable if you can recover them, but the prediction algorithm will recalibrate within 2-3 cycles even without historical temperature data.

## Clean up Kindara

Since Kindara is largely discontinued, the standard account deletion flow may not work. Try these steps in order:

1. Check the app's settings for a Delete Account option. If it exists, use it.
2. If no in-app deletion exists, check Kindara's website (or Prima-Temp's) for a privacy contact email. Submit a data deletion request citing CCPA or GDPR.
3. If no contact responds, file a deletion request through the app store where you downloaded Kindara, both Apple and Google have processes for requesting data deletion from app developers.

After attempting deletion through whatever channel is available, uninstall the app. An unmaintained app on your phone is an unnecessary attack surface even if you are not actively using it.
