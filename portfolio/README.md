# Portfolio

This is the retrospective, evidence-backed write-up of Floriva Web, for a reader
deciding whether the engineering here holds up (a hiring manager, a technical
reviewer, or anyone who wants more than the [README](../README.md)'s summary). Every
claim in these documents traces to a file, a command, or a named decision. Where a
number cannot be reproduced from this tree, the document that cites it says so rather
than restating it.

**If you read one thing**, read [`TESTING.md`](TESTING.md). It carries the argument
the rest of this portfolio makes in summary: what the 41 gates check, what each one
still cannot see, and the self-test that proves the mobile layout gate can actually
fail.
